# Tests are written in RSpec, not Rails' default Minitest

The maintainer prefers RSpec. The Rails scaffold ships Minitest (`test/`, fixtures); the implementation replaces it with `rspec-rails` (`spec/`) and the CI `test` jobs run `bundle exec rspec`. Anyone expecting the Rails default will find `spec/` instead of `test/`, hence this record. Toolchain: FactoryBot (no fixtures), request specs instead of controller specs, system specs on Selenium (headless Chrome, as in the scaffold) for the key flows only, axe-core-rspec (AA violations fail CI), shoulda-matchers, rubocop-rspec, i18n-tasks, SimpleCov for information only. `spec/domain` (the `Matcher`, prompt building) loads without Rails. Exact set is confirmed in the spec.
